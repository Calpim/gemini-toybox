  • もしプレイヤーがフロア内を探索して上り階段に到達する

シード値に基づき部屋・広め通路・上り階段を持つフロアを生成する

  • 前提現在のフロア番号が N (N >= 1) である
  • もしフロア生成エンジンが空間分割（BSP等）でマップを構築する
