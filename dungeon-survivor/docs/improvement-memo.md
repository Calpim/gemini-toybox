## 対応ステータスと残課題

### 1. シューター（固定砲台）＆通路リポップ抑制【実装済み / 数値は Inferred】
- **対応内容**: メモの「タンク敵」は `shooter` の誤記として訂正し、ノックバック無効・索敵拡張（`250px`）・8方向交互弾幕を実装。併せて狭い通路へのリポップを抑制（部屋限定）し、`caller` を `scout`（スカウト）へ改名して追撃ランナー速度を `228〜265 px/s`（プレイヤー `210px/s` 超）＋出現猶予 `0.45s` に更新。
- **関連**: `DEC-10`, `PRM-15`, `PRM-26`, `PRM-31`, `NG-11`, `NG-12`

### 2. プレイヤー装備（シールド・ブレード・Lv10上限）【実装済み / 数値は Inferred】
- **対応内容**: `pulse_blade` は360度化せず敵方向への扇形高火力・短CDを維持、`orbit_shield` は低ビット時の高速回転化・回転半径拡大・範囲内スロー（`0.72倍`）を実装。全装備上限を `Lv10`（Lv1〜6で展開進化最大、Lv7〜10は威力/CD/射程）とし、`ESC`/`K`/`⏸` で詳細確認可能なポーズ画面を整備。
- **関連**: `DEC-10`, `PRM-13`, `PRM-19`, `PRM-20`, `PRM-21`, `PRM-22`, `PRM-32`, `GLS-12`, `GLS-14`, `NG-10`

### 3. 3/6/9F 守護中ボス（ガーディアン）【実装済み / 数値は Inferred】

- **関連**: `DEC-10`, `PRM-14`, `GLS-07`, `INV-04`, `FML-09`
