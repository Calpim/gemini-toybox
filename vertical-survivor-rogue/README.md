# Vertical Survivor Rogue - Wing Laser Edition

スマートフォン片手で手軽に遊べる、縦スクロール型の防衛サバイバー・ローグライトゲームです。  
外部アセットやサーバーを一切使わず、単一の `index.html` だけで高音質なシンセウェーブ音楽・効果音と美麗グラフィックが動く完全自己完結型アーケード作品です。

---

## 🕹️ ゲーム概要

自機を操作して、上空から防衛ライン（自機背後）へ迫り来る大軍勢を迎撃せよ！  
敵を撃破してドロップするエナジージェムを回収し、レベルアップ時に提示される3枚のカードからスキルを選択・強化して生き残れ！

- **操作方式**: スマホ対応の「相対スワイプ操作」（指で自機が隠れない安心設計）
- **索敵迎撃**: 手前・至近距離を超ワイドに捕捉する「スマートオートロック」（すり抜け敵を最優先迎撃）
- **ステージ**: 宇宙・荒野・深海の3大戦場（ステージごとにBGMと環境パーティクルが変化）

---

## 🎮 操作方法

| デバイス | 操作方法 |
|---|---|
| **スマートフォン / タブレット** | 画面最下部の操作エリア（「TOUCH & SWIPE HERE」）を左右にスワイプ |

## ⚡ 強化スキル一覧（最大Lv 5）

1. **デュアルブラスター (主砲弾数)**: 正面への主砲弾数が増加（最大5連装斉射）
2. **プラズマウィングレーザー**: 自機左右にビットを配備し、前方に高火力レーザーを連続照射
3. **クラスターボム (自動爆撃)**: 敵密集地点へ自動で爆撃を投下し、広範囲を殲滅
4. **ホーミングミサイル**: 索敵範囲外の敵も自動追尾して粉砕する誘導弾
5. **ディフェンスシールド (自爆防壁)**: 自機背後の防衛コアHP上限＆即時回復、接触敵を電磁パルスで吹き飛ばす
6. **ショックチェーン (連鎖電撃)**: 着弾時に周囲の敵へ電撃が飛び火するチェインライトニング
7. **マグネットフィールド**: ドロップしたジェムの吸引範囲と吸引速度が大幅アップ

## 👾 敵ユニット種別

- **ノーマル**: 標準的な歩兵ユニット。群れをなして前進
- **ラッシャー**: 急加速して防衛ラインへ突撃してくる高速小型機
- **チェイサー**: 自機の位置をリアルタイムに計算し、方向転換しながら滑空するステルス戦闘機
- **シューター**: 遠距離から自機狙いプラズマ弾を発射してくる砲撃機
- **シージ (大型)**: 圧倒的な耐久力とコア破壊力を持つ大型要塞艦

## 🛠️ 技術的ハイライト

- **完全プロシージャル・サウンドエンジン (Web Audio API)**:
  - 外部オーディオファイルゼロ！ブラウザのオシレーターとホワイトノイズのみでリアルタイム合成。
  - ステージごとに曲調が変わる 16-Step Synthwave BGM シーケンサー ＆ 全9種の効果音（爆発サブベース、レーザー、ミサイル、ヒット音など）。
  - ヘッダーおよびスタート画面でのリアルタイム音量調整（Master Gain）対応。
- **パララックス・カメラドリフト**:
  - Geminiで生成した美麗なトップダウン背景画像を、自機移動に応じたリアルタイム視差（Parallax Shift）と低周波ブリージングで描画。
  - 継ぎ目（シーム）ゼロで、手前の高速パーティクル（砂嵐・気泡・星屑）との速度差が生み出す映画のような奥行きを実現。
- **Zero-Dependency**:
  - 画像データは Base64 Data URI で内包されており、オフライン環境やローカルファイル直接起動でも100%確実に動作。
